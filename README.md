# Constance — motorisation du projecteur laser

Installation de Luce Moreau, festival Gamerz, Aix-en-Provence, octobre 2013. Trois faisceaux laser perpendiculaires ; le module tourne lentement autour de l'axe du laser vert, aligné sur l'axe de rotation de la Terre, pour compenser celle-ci.

- `arduino/Laser_Motion/` : le croquis Arduino. Recherche du fin de course, course lente à vitesse constante, retour. Sorties PLS/DIR/ENA vers un driver de moteur pas à pas.
- `module-3-axes/` : les dessins du module à trois axes.
- `Connexion_PAP.jpg` : câblage du driver.
- `mise-en-situation/` : les vues préparatoires de la course des faisceaux.
- `photos/` : le montage et les essais, 2013.

Fiche du projet : https://electro-crea.com/projets/constance/ — œuvre de Luce Moreau.
